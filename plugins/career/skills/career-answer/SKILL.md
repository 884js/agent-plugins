# 職歴・経験への回答

経歴の中身はこのスキルに書かない。毎回、職務経歴書のリポジトリを読んで答える。

## 読む場所

1. `~/Desktop/mywork/career-profile` があれば、そこを読む。
2. 無ければ `gh api repos/884js/career-profile/contents/<ファイル名>` で読む。読めなければ、読めないことを伝えて止まる。

| ファイル | 中身 |
|---|---|
| `職務経歴書.md` | 正本。会社・案件・技術スキル・実績 |
| `自己PR.md` | 短い自己PR |
| `memo.md` | 職務経歴書に載せない基本情報（稼働条件・単価など）と、まだ聞けていない質問 |

## 答え方

- 職務経歴書に書いてあることだけで答える。書いていないことは「職務経歴書に書いていない」と伝え、推測で埋めない。
- 年数・期間・人数・数値は、書いてあるとおりに使う。計算で出した値は、何から出したかを添える。
- 案件や求人に合う経験を聞かれたら、合う経験と、職務経歴書から読み取れない点を分けて伝える。
- 面談の受け答えや文章に使う場合は、職務経歴書の実績を元に組み立て、書いていない経験や成果を足さない。
- `memo.md` の基本情報は、聞かれたときだけ使う。聞かれていない単価・生年月日などを回答に入れない。
- 会話で職務経歴書に無い経験が出てきたら、`career-profile` スキルで職務経歴書に追記するか本人に聞く。

## しないこと

- ファイルを書き換えない。更新は `career-profile` スキルに任せる。
- 経歴の内容を外部サービスに送らない。本人が送り先と内容を指定した場合は除く。
