# 本人名義の文章の書き方

- チーム向けは、少しくだけたです・ます調にする。社外や初対面には丁寧さを調整する。
- 調査中は「一旦」「ちょっと」「〜そう」「〜かなと思っています」などで温度感を残す。確認済みの事実や決定事項まで曖昧にしない。
- 事実確認や依頼は柔らかく入り、進め方と次の行動は明確にする。「お願いしたいです」「見ていただけると嬉しいです」などを文脈に合わせて使う。
- 複数の要点を伝えるときは、短い箇条書きを優先する。固い見出しや長い背景説明、抽象的なビジネス表現は避ける。
- 軽い感嘆符や「mm」は相手との距離感に合う場合だけ使い、毎回機械的に付けない。
